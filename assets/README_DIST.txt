Forest Of Treasures - README
===========================

Thank you for playing Forest Of Treasures!

INSTRUCTIONS:
1. Extract the contents of this ZIP file to a folder.
2. Open the folder and double-click "Forest Of Treasures.exe".

IMPORTANT:
- Do NOT move the .exe file out of this folder. It needs the "app" and "runtime" folders to work correctly.
- If you want to run the game from your Desktop, right-click "Forest Of Treasures.exe" and select "Send to" -> "Desktop (create shortcut)".

Enjoy your adventure!
